# Raymond & Joy Wedding Invitation

Static, self-contained HTML wedding invitation. The images and styles are embedded in `index.html`.

## Publish with GitHub Pages
1. Create a new public GitHub repository, e.g. `raymond-joy-wedding`.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then **Save**.
5. Wait for GitHub Pages to publish the site; the URL will appear in Settings → Pages.

Note: RSVP email delivery should be tested after publishing. Music playback requires a guest interaction due to browser autoplay rules.
